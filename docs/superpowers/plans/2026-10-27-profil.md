# Profil simplifié Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Carte « Mes stats » dans le Profil, liste des séances déplacée dans une page « Mon historique ».

**Architecture :** calcul pur `src/domain/stats.ts` ; lecture `src/data/stats.ts` ; écrans `StatsCard` (Profil) et `HistoryPage` (`/historique`), le détail d'une séance déplacé dans `src/features/history/WorkoutSheet.tsx`.

**Tech Stack:** React 18, TypeScript, Dexie, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-27-profil-design.md`

## Global Constraints

- Charge totale : séries `done`, `kind` ≠ `warmup`, charge > 0, reps > 0, séances terminées.
- Formats : « N séance(s) » ; « 45 min » / « 64 h » ; « 850 kg » / « 182,5 t » ; lb « 27 300 lb ».
- Libellés : « Mes stats », « 📅 Mon historique », « 🏆 Mes records », « Mon historique », « ‹ Profil », « Octobre 2026 · 12 séances », « Aucune séance terminée pour l’instant. ».
- Rien côté serveur.

## Review Focus

- Séance terminée sans `finished_at` (données anciennes) : ni plantage ni NaN dans les minutes.
- Historique de plusieurs centaines de séances : une seule lecture des séries.
- Séance commencée le 31 à 23 h 30 : rangée dans le mois de son début (`workoutDate`).
- Unité lb : la charge totale affichée en lb, jamais en tonnes.
- Profil vide (nouvel utilisateur) : « 0 séance », « 0 min », « 0 kg ».
