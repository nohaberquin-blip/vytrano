# Mon cycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Règles dans le Calendrier (avec prévision) et séance allégée les jours de règles, neutre pour la progression, pour les profils « Femme » seulement.

**Architecture :**
- Calculs purs : `src/domain/cycle.ts` (prévision) et `src/domain/lighten.ts` (allègement, réutilise `keepUnits` de fitTime).
- Données : table `periods` (Dexie v5 + Supabase 011), `workouts.lightened` ; `src/data/cycle.ts`.
- `planWorkout` → allègement → `fitToTime` ; `finishWorkout` et `lastSetsFor` ignorent les séances allégées.
- Écrans : points roses et fiche du jour dans le Calendrier ; `Lighten.tsx` dans Séance.

**Tech Stack:** React 18, TypeScript, Dexie, Supabase, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-25-cycle-design.md`

## Global Constraints

- Tout est invisible si le profil n'est pas `sex = 'female'`.
- Valeurs : durée 5 par défaut, 2 à 10 ; cycle 28 par défaut, moyenne des 3 derniers écarts valides (15 à 60 j) ; −10 % / −20 % arrondis avec `roundTo(·, fiche.rounding)` ; « Moins de séries » = 2 unités.
- Libellés : « Début des règles », « Durée (jours) », « Modifier la durée », « Supprimer ces règles », « Règles », « Règles prévues », « 🌸 Je ne me sens pas bien », « −10 % », « −20 % », « Moins de séries », « Annuler », « Séance allégée ».
- Le script 011 doit être exécuté avant la publication.

## Review Focus

- Profil non « Femme » (ou sans profil) : aucune trace du mode, même si des règles existent en base.
- Séance allégée réussie : la charge ne monte pas ; la séance suivante et « la dernière fois » repartent de la dernière séance normale.
- Allègement + temps limité ensemble : les deux s'appliquent, dans cet ordre.
- Supprimer ou raccourcir une période recalcule la prévision.
- Une charge à 0 (poids du corps) reste à 0.
