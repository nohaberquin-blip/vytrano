# Accueil façon iPhone Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Accueil en grille d'icônes avec widgets, personnalisable et synchronisé ; plus de barre du bas ; bouton flottant de séance en cours.

**Architecture :**
- Calculs purs : `src/domain/home.ts` (catalogue, disposition, opérations) et `src/domain/homeWidgets.ts` (prochaine séance, objectifs du jour).
- Données : colonne `profiles.home` (migration 014), `saveHome` dans `src/data/profile.ts`, `patchProfile` dans `AuthProvider`.
- Écrans : `src/features/home/` (`HomePage`, `Widgets`, `EditBar`/feuille d'icône), `src/features/nutrition/NutritionPage.tsx`, `src/app/SessionFab.tsx`, en-tête dans `App.tsx`.

**Tech Stack:** React 18, TypeScript, Dexie, Supabase, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-29-accueil-design.md`

## Global Constraints

- Adresses : `/` Accueil, `/seance` Séance, `/nutrition` Nutrition ; `TabBar` supprimée.
- Icônes, emojis, couleurs par défaut et ordre : table §4 de la spec ; 9 couleurs `red orange yellow green teal blue indigo purple gray`.
- Libellés : « ‹ Accueil », « Modifier l'accueil », « Terminé », « Réinitialiser », « Masquer », « Afficher », « Masqués »,
  « Prochaine séance », « Progression », « Calories », « Objectifs du jour », « Séance du jour », « Choisis un programme »,
  « Complète ta fiche », « Rien de prévu aujourd'hui », « Accueil non enregistré, réessaie plus tard. », « Reprendre la séance, N min ».
- Paramètres jamais masquable ; valeur `home` abîmée → disposition par défaut, sans erreur.
- Migration `014_accueil.sql` à exécuter avant la publication.

## Review Focus

- Profil sans colonne `home` (migration pas encore faite) ou hors ligne : l'accueil s'affiche par défaut, modifier affiche le message d'échec sans perdre la disposition à l'écran.
- Revenir sur l'accueil après une modification (autre page puis retour) : la nouvelle disposition reste (contexte mis à jour, pas l'ancien profil).
- Glisser-déposer : un simple toucher en mode Modifier ouvre la feuille de couleur, un glisser ne l'ouvre pas ; hors mode Modifier, l'appui long n'ouvre pas la page.
- Bouton flottant et barre de repos à l'écran ensemble : rien ne se chevauche, le bas des pages reste atteignable.
- Séance terminée aujourd'hui sur un jour prévu : « Prochaine séance » passe au jour prévu suivant, « Séance du jour » est cochée.

### Task 1: Calculs (disposition et widgets)

**Files :** Create `src/domain/home.ts`, `src/domain/homeWidgets.ts` (+ tests)

```ts
// home.ts
export type AppId = 'session' | 'calendar' | 'programs' | 'exercises' | 'nutrition' | 'friends' | 'profile' | 'settings'
export type WidgetId = 'next' | 'progress' | 'calories' | 'goals'
export type IconColor = 'red' | 'orange' | 'yellow' | 'green' | 'teal' | 'blue' | 'indigo' | 'purple' | 'gray'
export const APPS: { id: AppId; label: string; emoji: string; to: string; color: IconColor }[]   // table §4
export const WIDGETS: { id: WidgetId; label: string }[]
export const COLORS: IconColor[]
export interface HomeLayout { apps: AppId[]; hiddenApps: AppId[]; colors: Partial<Record<AppId, IconColor>>; widgets: WidgetId[]; hiddenWidgets: WidgetId[] }
export const DEFAULT_LAYOUT: HomeLayout
export function readLayout(raw: unknown): HomeLayout
export const appColor: (l: HomeLayout, id: AppId) => IconColor
export function moveApp(l: HomeLayout, id: AppId, target: AppId): HomeLayout      // id prend la place de target
export function moveWidget(l: HomeLayout, id: WidgetId, target: WidgetId): HomeLayout
export function setAppHidden(l: HomeLayout, id: AppId, hidden: boolean): HomeLayout  // settings : inchangé
export function setWidgetHidden(l: HomeLayout, id: WidgetId, hidden: boolean): HomeLayout
export function setAppColor(l: HomeLayout, id: AppId, c: IconColor): HomeLayout
// homeWidgets.ts
export function nextSession(input: CalendarInput | null, days: ProgramDay[], lastDoneDayId: string | null, today: string):
  { date: string | null; day: ProgramDay } | null       // null = pas de programme
export function whenLabel(date: string, today: string): string  // « Aujourd'hui », « Demain », « Jeudi », sinon « 12 novembre »
export interface DailyGoals { today: { done: boolean } | null; month: { done: number; goal: number } | null;
  challenge: { c: Challenge; p: ChallengeProgress } | null }
export function dailyGoals(data: MonthData): DailyGoals
```

- `nextSession` : avec calendrier, premier jour `planned` de `buildCalendar(input, today, today + 13)` (son `day`, sinon `nextDay`) ; sans jour prévu sur 14 jours ou sans calendrier : `{ date: null, day: nextDay(days, lastDoneDayId) }`.
- `dailyGoals` : `today` si `isPlanned(today)` (fait = une séance terminée datée d'aujourd'hui) ; `month` si `monthGoal(...).goal > 0` (séances terminées du mois) ; `challenge` = défi non `month` `active` à la fin la plus proche.

- [ ] Tests `home` : défaut ; `readLayout(null | 'x' | {apps: 3})` → défaut ; ids inconnus et doublons ignorés, manquants ajoutés à la fin ; `hiddenApps: ['settings']` ignoré ; couleur invalide ignorée ; `moveApp(d, 'friends', 'session')` → friends en tête ; `moveApp` vers soi-même inchangé ; masquer/afficher ; `setAppHidden(d, 'settings', true)` inchangé ; `setAppColor`.
- [ ] Tests `homeWidgets` : sans programme → null ; sans calendrier → `date: null` et jour suivant de la rotation ; aujourd'hui prévu non fait → aujourd'hui ; fait → jour prévu suivant avec le jour suivant du programme ; `whenLabel` (aujourd'hui, demain, dans 3 jours = nom du jour avec majuscule, dans 10 jours = « 12 novembre ») ; `dailyGoals` : jour non prévu → `today: null`, prévu fait, objectif du mois, défi le plus proche (deux actifs, un échoué), aucun.
